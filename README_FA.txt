وب‌اپلیکیشن آموزشی مدرسه مهد دانش — نسخه نمایشی اولیه

محتویات:
- index.html: ساختار و صفحه‌های برنامه
- style.css: طراحی واکنش‌گرا، فارسی و راست‌چین
- app.js: تعاملات، درس‌ها، آزمون و ذخیره محلی
- manifest.json: تنظیمات وب‌اپلیکیشن قابل نصب
- sw.js: سرویس‌ورکر برای کش و پشتیبانی آفلاین پایه
- logo.svg: آرم نمونه سرمه‌ای و طلایی

روش اجرای سریع:
1) فایل ZIP را استخراج کنید.
2) برای مشاهده سریع، index.html را در مرورگر باز کنید. در این حالت بعضی قابلیت‌های PWA و آفلاین فعال نمی‌شوند.
3) برای نصب‌پذیری و آفلاین، فایل‌ها باید از طریق HTTPS یا localhost سرو شوند.
4) ساده‌ترین راه روی رایانه: در پوشه برنامه، دستور `python -m http.server 8000` را اجرا کنید و در همان دستگاه به `http://localhost:8000` بروید.
5) برای دسترسی از گوشی در همان شبکه، از آدرس IP رایانه به همراه پورت 8000 استفاده کنید؛ برای استفاده بیرون از شبکه، آن را روی میزبانی HTTPS مانند GitHub Pages یا سرویس مشابه منتشر کنید.
6) در اندروید، صفحه منتشرشده را با Chrome باز کنید، منوی سه‌نقطه را بزنید و «Install app» یا «Add to Home screen» را انتخاب کنید. نام گزینه بسته به نسخه مرورگر متفاوت است.

نکته مهم:
این نسخه MVP نمایشی است، نه سامانه عملیاتی مدرسه. نتایج، پروفایل و بازخوردها فقط در localStorage همان مرورگر ذخیره می‌شوند. ورود امن، سرور، پایگاه داده مشترک، نقش‌های واقعی و همگام‌سازی بین دستگاه‌ها هنوز پیاده‌سازی نشده‌اند. بخش‌های معلم و مدیریت نمونه رابط کاربری هستند و کنترل دسترسی واقعی ندارند. برای اطلاعات واقعی کودکان از نسخه فعلی استفاده نکنید.
